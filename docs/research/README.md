# Research — Renda Comparada

Este diretório contém materiais de pesquisa, evidências, protocolos, propostas, experimentos, rascunhos e artefatos auxiliares do projeto Renda Comparada.

## Autoridade

Os arquivos desta pasta são, por padrão:

> **NÃO CANÔNICOS**

A existência de um documento em `docs/research/` não altera automaticamente:

- visão do produto;
- escopo da V1;
- metodologia;
- decisões;
- privacidade;
- contratos técnicos;
- datasets de produção;
- frontend;
- estado de uma fase.

Pesquisa produz evidência e proposta.

Canonização exige decisão explícita e atualização das fontes de autoridade correspondentes.

Para a fotografia resumida do estado corrente, consulte `../README.md`. Para o fluxo permanente ChatGPT ↔ Codex, consulte `../operacao-chatgpt-codex.md`.
